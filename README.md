# Reference-Free Image Quality Assessment for Virtual Try-On via Human Feedback
This repository is the official implementation of the paper "Reference-Free Image Quality Assessment for Virtual Try-On via Human Feedback".

## Quality Assessment of Try-On Images

Please download the pretrained VTON-IQA model and place the files under the `./ckpt` directory. You can download the model files by running the following command:
```bash
python util/download.py --target vtoniqa --outdir ckpt
```
The directory structure should look like:
```bash
├── ckpt/
│   ├── config.json
│   ├── target_scaler.pkl # Use for testing VTON-IQA itself. 
│   └── model.safetensors
```

### IQA on single query.

```python
from app import VTONScorerOnce

scorer_model_root = "ckpt"
scorer = VTONScorerOnce(scorer_model_root)

person = "path/to/person"
garment = "path/to/garment"
tryon = "path/to/tryon"

score = scorer(person, garment, tryon)
print(score)
```

### Interactive Demo
We provide an interactive demo built with Gradio.
To launch the demo locally, run:

```bash
python app.py --scorer_model_root=ckpt
```

### Batch IQA on VITON-HD or Dress Code test set.

The VITON-HD and Dress Code datasets can be downloaded from their respective official repositories:
- VITON-HD: [here](https://github.com/shadow2496/VITON-HD)
- Dress Code: [here](https://github.com/aimagelab/dress-code)

After downloading, please organize the datasets in the following directory structure:

```bash
├── YOUR_DATASET_ROOT/
    ├── DressCode/
    └── vitonhd/
```

Set the environment variable DATASET_ROOT and run:

```bash
DATASET_ROOT=YOUR_DATASET_ROOT python vtoniqa.py config=config/vtoniqa.yaml dataset_type={vitonhd|dc} vton_images_root=path/to/vtons
```
All try-on images must be placed directly under `path/to/vtons`.

Each image must follow the naming convention:

```bash
{person}_{garment}.{jpg|png}
```
For example, if:
```bash
person="048392_0.jpg"
garment="049114_1.jpg"
```
then the try-on image should be named as;
```bash
048392_0_049114_1.{jpg|png}
```

We provide try-on images generated by VITON-HD, HR-VITON, LADI-VTON, SD-VITON, CAT-DM, OOTDiffusion, IDM-VTON, CatVTON, CatVTON-FLUX, FitDit, Any2AnyTryon, Qwen-Image-Edit, Nano Banana Pro, and GPT-Image-1.5 on the test sets of VITON-HD and Dress Code.

You can download try-on images by running the following command:

```bash
python util/download.py --target test --outdir YOUR_DATASET_ROOT
```

## Training and Evaluation of VTON-IQA

Please download VTON-QBench by running the following command:

```bash
python util/download.py --target vtonqbench --outdir YOUR_DATASET_ROOT
```

The VITON-HD and Dress Code datasets can be downloaded from their respective official repositories:
- VITON-HD: [here](https://github.com/shadow2496/VITON-HD)
- Dress Code: [here](https://github.com/aimagelab/dress-code)

After downloading, please organize all datasets in the following directory structure:

```bash
├── YOUR_DATASET_ROOT/
    ├── DressCode/
    ├── vitonhd/
    ├── synth_vton/
    └── vtonqbench/
        ├── images
        │   ├── triplets #pseudo-triples
        │   └── vtons #try-on images
        ├── answers.csv #raw annotation results.
        ├── images.csv #raw annotation results.
        ├── train.json 
        ├── valid.json
        └── test.json
```

### Training
Run the following command to train VTON-IQA:
```bash
DATASET_ROOT=YOUR_DATASET_ROOT python train.py config=config/train.yaml
```

### Evaluation
Run the following command to evaluate the model:
```bash
DATASET_ROOT=YOUR_DATASET_ROOT python test.py config=config/test.yaml scorer_model_root=ckpt
```

Before running evaluation, place the trained model files under the `./ckpt` directory. The directory structure should be organized as follows:
```bash
├── ckpt/
│   ├── config.json
│   ├── target_scaler.pkl
│   └── model.safetensors
```
